### Planner Response

To run the **UITS Research Archive** project locally, follow these steps. Since this is a Laravel project, you will need **PHP (8.2+)**, **Composer**, **Node.js**, and a database (SQLite is configured by default).

### 1. Install Dependencies
Open your terminal in the project root and run:
```bash
composer install
npm install
```

### 2. Environment Setup
Create your environment configuration file from the example provided:
```powershell
copy .env.example .env
```
Then, generate the application key:
```bash
php artisan key:generate
```

### 3. Database Setup (Default: SQLite)
The project is configured to use **SQLite** by default, which is the easiest way to get started.
1. Create an empty database file in the `database` folder:
   ```powershell
   New-Item -Path "database/database.sqlite" -ItemType File
   ```
2. Run the migrations and seed the database with initial data (departments, domains, and sample users):
   ```bash
   php artisan migrate --seed
   ```

### 4. Run the Project
You can run the full development environment (server + vite assets) using the custom command defined in `composer.json`:
```bash
composer dev
```
*Alternatively, you can run them in separate terminals:*
*   `php artisan serve` (Backend)
*   `npm run dev` (Frontend assets)

### 🛠️ Troubleshooting
*   **Vite Errors**: If the UI looks unstyled, ensure `npm run dev` is running.
*   **Database Errors**: If you prefer MySQL, update the `DB_*` variables in your `.env` file before running the migration command.
