# Hosting Laravel 12 on Vercel

This plan outlines the steps required to adapt this Laravel 12 application for deployment on Vercel. Since Vercel uses a serverless, read-only filesystem (except for `/tmp`), we need to bridge requests and redirect temporary files like compiled Blade views.

## User Review Required

> [!IMPORTANT]
> **Ephemeral Filesystem**: Vercel's filesystem is read-only and resets on every request. This means:
> - User-uploaded files (PDFs, images) **must** be stored on an external service like AWS S3 or Cloudinary.
> - **Supabase Database (PostgreSQL)**: You must use the Connection String or Host/Port details from your Supabase project. The `DB_CONNECTION` should be set to `pgsql`.
> - Logs are redirected to `stderr` and can be viewed in the Vercel dashboard logs.

### 4. Supabase (PostgreSQL) Configuration
Since you are using Supabase, ensure the following environment variables are set in Vercel:
- `DB_CONNECTION`: `pgsql`
- `DB_HOST`: Your Supabase host (e.g., `db.yourproject.supabase.co`)
- `DB_PORT`: `5432`
- `DB_DATABASE`: `postgres` (or your specific DB name)
- `DB_USERNAME`: `postgres`
- `DB_PASSWORD`: Your Supabase database password
- `DB_SSLMODE`: `require` (Supabase often requires SSL)
