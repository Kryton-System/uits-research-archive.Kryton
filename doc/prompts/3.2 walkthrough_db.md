## How to Deploy the Database

You have two options to set up your Supabase database:

### Option A: Using the Supabase SQL Editor (Fastest)
1. Open your Supabase project.
2. Go to the **SQL Editor** in the sidebar.
3. Open [database_pgsql.sql](file:///e:/Git_WIP/3.%20University%20repositories/uits-research-archive.Kryton/database_pgsql.sql), copy its entire content, and paste it into the Supabase editor.
4. Click **Run**.

### Option B: Using Laravel Migrations (Recommended for Vercel)
Once you have connected your repository to Vercel and added the environment variables:
1. Temporarily add a route in `web.php` or run it locally by pointing your `.env` to Supabase:
   ```bash
   php artisan migrate --seed --force
   ```
   *Note: Using `--seed` will automatically populate the departments, domains, and sample users via the `DatabaseSeeder.php` I verified earlier.*
